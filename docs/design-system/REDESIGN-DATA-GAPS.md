# Redesign data gaps

The 2026-10-27 redesign (canvas https://claude.ai/artifact/AYvi7UAZ6AFkbVKgPRnGMk)
draws some elements that need data the server may not provide yet.

When data is missing, the UI omits the element. It does not invent it or show a
placeholder dash (see "Missing optional metrics" in BLAST-DESIGN-SYSTEM.md).

This list records each such element and the backend work that closes it. The
UI pass recorded the gaps; a separate backend worker builds the reads, the
contracts and the infrastructure, and wires each field into the redesigned
components once the redesign PR has merged.

Status values:
- **gap**: confirmed missing; the UI omits the element.
- **building**: the read is being built; the UI still omits the element.
- **done**: the data is served (PR named); the UI may draw the element.
- **won't build**: no read will serve it; the reason and the alternative are in the notes.
- **ok**: the data already existed and the element is built.
