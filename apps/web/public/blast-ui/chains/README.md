Bridge to Sui uses local Base, Ethereum, Arbitrum, Optimism, Polygon and Solana logos to identify source chains and their native coins (Ethereum's mark stands for ETH, Polygon's for POL, Solana's for SOL). The files are the branded network marks from `@web3icons/core` 4.0.58 (MIT), with the `class` attribute removed. The marks belong to their respective owners and are separate from the app's Apache 2.0 license.
